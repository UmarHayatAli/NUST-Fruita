# Decisions

Choices made where the spec (docs/SPEC.md, v2) is silent or contradicts itself.
Newest at the bottom.

| #   | Date       | Decision                                                                                                                                               | Why                                                                                                                                                                                                         |
| --- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | 2026-11-24 | Stack is Node + Express (not Flask).                                                                                                                   | Change log C14 fixes the stack; it overrides the Flask option in 6.1.                                                                                                                                       |
| D2  | 2026-11-24 | Local development uses the developer's own MySQL install; `docker-compose.yml` (MySQL only) stays optional.                                            | Spec 6.2 says compose is "MySQL only (optional)"; the "definition of done" line about compose starting the API is read as "or the manual steps".                                                            |
| D3  | 2026-11-24 | `engines.node` is `>=20`; CI runs Node 20.                                                                                                             | Spec asks for Node 20 LTS; developers on newer Node versions are not blocked.                                                                                                                               |
| D4  | 2026-11-24 | The two MySQL accounts are created by `db/scripts/create-users.js` (Node) instead of a `.sql` file.                                                    | Passwords come from `.env`, so none are committed; works the same on Windows and in CI. The script also creates the empty `fruita` and `fruita_test` databases so `/api/health` can connect before Phase 1. |
| D5  | 2026-11-24 | Accounts use host `'%'`.                                                                                                                               | Works for both a local install and Docker.                                                                                                                                                                  |
| D6  | 2026-11-24 | All packages use ES modules (`"type": "module"`).                                                                                                      | One module style across server, web and shared; Vite and Vitest expect it.                                                                                                                                  |
| D7  | 2026-11-24 | The pool sets `SET time_zone='+05:00'` on every connection and mysql2 `timezone: '+05:00'`. The migration and seed scripts (Phase 1) must do the same. | Slot checks compare against `NOW()`, which depends on the session time zone (A12).                                                                                                                          |
